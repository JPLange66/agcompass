What the defaults actually are

Input lines and sponsor slots

Each line has a supplier field and an editable quoted price so a live rep quote can sit next to the public feed. Sponsorships are inventory slots only — no company has signed. Default is that these line totals are not added into profit, because UA field-crop operating costs already include fertilizer, seed, chemicals, and machinery. Quantities start at 0 for that reason.

Opportunity cards
